## 一、什么是腾讯 ima 知识库

[腾讯 ima](https://ima.qq.com/) 是腾讯推出的 AI 知识库工具。它的用法和"收藏夹""网盘"不一样，值得先说清楚这三点：

**1. 它是一个"能被提问的知识库"**
普通收藏工具的逻辑是"存下来，以后自己翻"。ima 的逻辑是"丢进一堆资料，之后**直接用中文问它**"。你可以把行业资料、模板、笔记、网页、公众号文章放进去，它会基于你放入的内容回答问题，并给出引用来源。

**2. 内容装在"知识库"这个容器里**
一个知识库 = 一组资料 + 一套 AI 问答能力。你可以建多个知识库，各自管一个领域；也可以把知识库**公开分享**，别人打开链接就能看目录、订阅，然后把自己的资料加进来一起问。

**3. 支持订阅和扫码加入**
分享者生成"知识码"二维码，读者用微信扫一下就能订阅这个知识库。订阅后，内容会持续更新——订阅的人拿到的是**活的内容流**，不是一份静态文档。

> 简单说：**ima 知识库 = 可订阅 + 可提问 + 会持续更新的专业资料库**。
> 它特别适合做一件事：把散落在微信收藏、公众号、网盘、本地文档里的行业经验，整理成一个别人能一键接入的"外挂大脑"。

## 四、订阅之后怎么用（3 个真实场景）

**场景一 · 面试前急用模板**
问："给我 3 个适合猎头顾问的自我介绍话术，风格分别正式/接地气/30 秒版。"
知识库会基于**已订阅内容**作答并标注出处，比自己翻收藏夹快得多。

**场景二 · 拆解一份 JD**
把客户的 JD 贴进去问："这个岗位的候选人画像是什么？面试该重点问哪 5 个问题？"

**场景三 · 攒自己的行业库**
订阅只是起点。更实用的做法是：把自己手上正在跑的**岗位、话术、谈判记录、候选人模板**也丢进 ima，问"这个候选人的薪酬锚点在哪、下一通电话该问什么"——这才是顾问真正的杠杆。

> 想把这一套玩得更深，可以看看同作者的另一个开源项目：**[talent-profile-diagnosis](https://github.com/dzc55551-eng/talent-profile-diagnosis)**（简历 → 带证据分级的人选寻访决策档案包）。
