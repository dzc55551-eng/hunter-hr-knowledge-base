# 推广指南｜GitHub + 微信双渠道

> 目标：**让对的人刷到 → 扫码订阅 → 进社群 → 反向产出内容 → 再被更多人看到**
>
> 现状：6364 个内容 / 4734 人订阅。内容资产已经很厚，缺的是**分发链路**和**可被搜索到的入口**。

---

## 一、先想清楚一件事：GitHub 和微信各自解决什么问题

| | GitHub | 微信（扫码） |
|---|---|---|
| 解决 | **可被发现**（搜索、榜单、外部链接） | **可被转化**（扫码即订阅） |
| 优势 | 长尾流量、搜索引擎收录、可被同行转发引用 | 转化路径最短，几乎零摩擦 |
| 弱点 | 中文用户不主动逛，转化链路长 | 无外部搜索入口，封在生态内 |
| 定位 | **引流中转站** | **最终沉淀地** |

> **别把 GitHub 当主战场。** 它的价值是"让内容有一个公开、可引用、可被搜索引擎收录的落地点"，然后把人导流到微信。真正的增长飞轮在微信侧。

### 2. 让 GitHub 帮你带量的 5 个动作

**① 养一个"profile README"**
在 `dzc55551-eng/dzc55551-eng` 这个同名仓库放一份个人主页 README，顶部放：
```
猎头HR全能知识库 · 6364个内容 · 4734人订阅
```
GitHub 个人主页是访问者必看页面，等于一个免费广告位。仓库 Star 涨了，个人主页也会被看到。

**② 让目标用户能找到你**
在 README 里写清"适用人群"（猎头顾问 / HR / 用人经理 / 求职者），每个身份都能自我代入。**不同身份要用不同的话去搜你**，这也是 README 标题里堆了 `hunter / recruiting / hr / resume` 等多组关键词的原因。

**③ 提交到 Awesome / 收录列表**
GitHub 上有大量中文 Awesome 列表（招聘、HR、效率工具方向）。找 3-5 个相关列表提 PR，把本仓库加进去。**这类列表的流量是持续的**，比单次发帖强得多。

**④ 主动在 Issue 区做"需求承接"**
在 Issues 里开一个模板 Issue：「我想让知识库补 XX 主题」。看到需求就更新，更新后回帖关闭——这既是内容来源，也是社区参与度的信号（GitHub 排序会参考 issue 活跃度）。

**⑤ 让同行的仓库引你**
你已有的 [talent-profile-diagnosis](https://github.com/dzc55551-eng/talent-profile-diagnosis) 和 [Robot-Recruitment-Zone](https://github.com/dzc55551-eng/Robot-Recruitment-Zone) 都是精准流量池，在它们 README 里互相加链接。同行会点开，你的知识库就进入了他们的读者视野。

### 3. 注意事项

- **不要**在 README 堆砌"全网最全""必收藏""资源合集第一"这类词——既降低可信度，也可能被 GitHub 判为垃圾内容降权。**用真实数字（6364/4734）和具体内容名**说话。
- **不要**在这个仓库里直接倒全部内容正文。只放索引、目录、精选条目和订阅入口。全量内容在 ima 里，这样仓库轻、聚焦、可长期维护。

## 三、微信侧：把扫码变成动作

### 1. 三个二维码场景（对应三种流量）

| 场景 | 用哪个码 | 话术方向 |
|---|---|---|
| **朋友圈/公众号** | 带 ima 水印的知识码原图 | "扫描订阅，知识库持续更新" |
| **GitHub / 技术社区** | 裁剪后的纯二维码方块 | 配文字说明 + 链接 |
| **社群/1v1** | 纯二维码方块（现场可扫） | "先扫码看目录，觉得有用再聊" |

> ⚠️ **重要发现**：你发来的**整张知识码图扫码失败**（已用解码器验证），但从中裁出的**纯二维码方块可正常识别**，指向链接完全一致。
> 原因：整图是二次压缩+缩放过的，宽高比被轻微拉伸，微信/相机容错解码失败。
> **对外传播请优先用 `assets/qrcode-only.png`**，并保持原始尺寸勿再压缩。需要带文案的版本时，把纯二维码放在**新画布**上（不要缩放原图），再叠文字。

### 3. 私聊/社群推广的关键动作

**① 先给价值，再给码**
不要上来就甩二维码。先发一张截图或一段真实答案（用知识库问出来的），对方回复"有意思"再给码。**转化率差 3-5 倍。**

**② 让订阅者产出内容**
订阅后引导他们提需求：「你在带什么岗位？我让知识库补 XX」。被问到的人有归属感，也顺手产出了新内容。

**③ 建"大本营"承接流量**
知识库里已经有「猎头/HR大本营」模块。扫码 → 订阅 → 进群，这条路径本身就是完整的漏斗。群里每周固定更新（每周一个专题 + 3 条精选），比每天刷屏有效。

**④ 沉淀可转发物**
知识库里已有的《猎头AI赋能图谱》这类内容，**单独导出一页做成图文**，是极好的转发物料——因为转发者不用解释什么是 ima。

## 六、常见坑

| 坑 | 说明 | 做法 |
|---|---|---|
| 把 GitHub 当主战场 | GitHub 中文用户不主动逛 | GitHub 只做"可被搜到的落地点"，主战场在微信 |
| 一上来就发二维码 | 无信任铺垫，转化极低 | 先给价值（截图/答案），再给码 |
| README 写成营销页 | 可信度掉，还可能被降权 | 用真实数字和具体内容名 |
| 主题名堆中文 | GitHub topic 拒绝中文，422 | 用英文 topic 覆盖搜索 |
| 二次压缩二维码 | 整图扫码失败（已实测） | 用 `assets/qrcode-only.png`，勿再缩放 |
| 内容全量塞仓库 | 仓库臃肿、更新难 | 仓库放索引，正文留 ima |
| 只发一次就不管了 | 冷启动无复利 | 固定节奏，每周至少 2 次触达 |
